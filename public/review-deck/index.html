⚠️ 착수 전 반드시 수정

원본 명세서가 ‘가능’으로 적었으나 실제로는 불가능한 3건

개발 3~4개월차에 발견되면 해당 기능을 통째로 다시 설계해야 합니다. 가장 먼저 고쳐야 할 항목입니다.

01

전원키 5회 연타는 Android에서도 불가능합니다

명세서는 AccessibilityService로 ‘가능(우회)’이라 적었지만, KEYCODE_POWER는 PhoneWindowManager가 앱 디스패치 이전에 선점합니다. 볼륨키만 수신됩니다.

→ 덱 슬라이드 9의 ‘전원버튼 5회’를 볼륨키로 전면 교체

02

iOS 라스트 비콘은 페이로드가 나가지 않습니다

백그라운드 전환 시 iOS가 Manufacturer Data와 Local Name을 광고 패킷에서 제거합니다. ‘수색 드론이 스캔만으로 좌표·혈액형을 판독’하는 시나리오는 iOS에서 성립하지 않습니다.

→ Android 전용 기능으로 명시

03

‘스텔스’라는 단어가 성립하지 않습니다

마이크 사용 중에는 iOS 주황 점 · Android 초록 점 인디케이터가 OS 레벨에서 강제 표시되며 어떤 앱도 숨길 수 없습니다. 원본 문서 어디에도 언급되지 않은 사각지대입니다.

→ ‘들키지 않는 녹음’으로 약속 불가

추가로 짚어야 할 설계 결함  —  BLE 비콘 페이로드에 혈액형·기저질환을 평문 브로드캐스팅하는 설계는 민감정보를 불특정 다수에게 무선 송출하는 것입니다. 비콘에는 회전식 익명 ID + 좌표만 싣고, 의료정보는 서버 조회 구조로 변경해야 합니다.
